# 厳選期待値 — ポケモンスリープ厳選期待値計算 PWA

**v1.1.27（新しい厳選期待値アイコンへ差し替え）** ／ Android Chromeでインストール可能な、グラフなしの厳選計算機です。

## 機能

- 希望サブスキルの AND 条件（Lv.10 / 25 / 50 / 70 / 80）、除外条件、サブスキルのたね（初期ON、手動でOFF可能）
- 性格25種を上昇能力別の6グループで表示。5つの上昇グループは4性格を一括選択・解除でき、個別指定も可能。無補正の5種類はまとめて1つの選択項目に変更。食材構成は候補3種類／2種類の切替に対応
- **金確定0・1・2・3枠の「出現確率」と「期待捕獲数」を一括計算・比較**
- フレンドレベル・金枠数の入力なし。0〜3枠は先頭からの連続金確定を表す
- 端末内に条件保存、計算結果コピー、オフライン計算
- 外部ライブラリ・外部通信・サーバー側計算なし

## インストール手順（Netlify）

1. ZIP を解凍し、`index.html` が直下にあるフォルダを用意する。
2. [Netlify Drop](https://app.netlify.com/drop) へフォルダをアップロードする。
3. 発行された HTTPS URL を Android Chrome で開く。
4. Chrome の `︙` メニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ。
5. インストール後、ホーム画面から起動する。初回オンライン読込完了後はオフラインで使用可能。

GitHub Pages への配置もできます（相対パス構成）。`file://` から直接開くのではなく、HTTPS で配信してください。PWA は APK ではありません。

## 計算前提

- サブスキル17種を順序付き・重複なし、相対重み付きで5枠抽選。金7種は各2%、青6種は各6%、白4種は各12.5%という**非公式の推定比率**を使用。
- 金確定枠は、先頭0/1/2/3枠を残りの金スキルから抽選。後続は重みを再正規化。
- 性格25種は等確率。食材候補が3種類の場合、AAA/AAB/AAC は各1/9、ABA/ABB/ABC は各2/9。2種類の場合、AAAは1/9、AAB/ABAは各2/9、ABBは4/9（AAC/ABCは候補外）。
- 3要素は独立抽選と仮定。サブスキルの条件は異なる枠にマッチングして全件成立を判定。たね使用時は複数回の昇格順も含め、ゲームで実現可能な最終構成を探索（たね所持数、ランダム抽選に要するたねの期待消費数は考慮しない）。
- 期待捕獲数は `1 / 出現確率`。0%の場合「達成不可」と表示。小数を整数へ切り上げない。
- メダルによる非連続の金確定 ON/OFF（例：Lv.10をOFF、Lv.25だけON）は今回の4パターンには含まない。

ゲームの公式抽選重みではないため、出現確率と期待捕獲数は推定値です。元サイトの計算プログラムや実際の出力との厳密一致は確認されていません。また、一般ポケモンの17スキル5枠モデルを想定し、ひらめきのたねを使う幻のポケモンなどの特殊仕様は対象外です。

優先参照：[攻略・検証Wiki](https://wikiwiki.jp/poke_sleep/サブスキル) ／ [RaenonX：サブスキル](https://hackmd.io/@raenonx-pokemon-sleep/Syeb8kLlbg) ／ [RaenonX：食材](https://hackmd.io/@raenonx-pokemon-sleep/rJj6yeIlWe)

## v1.1.1監査修正

- **たね複数使用の到達可能性**: 最大所持数アップS＋Mを持っていてLがない場合は、M→L、S→Mと順番に昇格可能。旧版はS→Mを誤って失敗扱いしていたため、重複なし・昇格可能性の全探索へ修正。
- **食材候補が2種類のポケモン**: 旧版は常に3種類用の食材比率を使っていた。候補数切替を追加。3種類がデフォルトなので従来の設定を保持する。
- **公開データの精度限界**: 有志Wikiの早見表は近似値で、重複なしの再正規化抽選と数値が一致しない場合がある。実際のゲーム抽選重み自体が未公開で、完全な正確性は保証できない。

監査詳細は `AUDIT_REPORT_20261031.md` を参照してください。

## v1.1.2 再監査修正（攻略・検証Wiki／RaenonX優先）

- **たねの解放レベル制限を適用**：未解放スキルはたねで強化できないため、各希望レベルまでに実行可能な昇格だけを許可。例：Lv.10の最大所持数アップSが、Lv.80の最大所持数アップMにブロックされている場合、Lv.80でM→Lを行ってからLv.10のS→Mと強化する操作は「Lv.10までにMを得る」の達成とは扱わない。
- **出現確率差**：希望「最大所持数アップM／Lv.10まで」、たねON、金確定0枠は旧17.68399458% → 新14.90534034%、期待捕獲数は約5.65匹 → 約6.71匹。独立DP照合一致。
- **たねONの解釈**：必要な回数のたねを確保でき、レベル解放後に使用することを想定。たね数、費用、実際の複数候補でのランダムな抽選回数は算出しない。除外は捕獲時の元サブスキル構成に対して適用。
- **主参照**：攻略・検証Wikiのサブスキル・たね・食材・フレンドメダル、およびRaenonX公式の食材構成・サブスキル解説。RaenonXのインタラクティブな抽選確率計算画面での厳密な入出力比較は利用上の制約により未実施。
- 金2%・青6%・白12.5%は公認確率ではなくWiki掲載の近似比率であり、RaenonX内部モデルとの完全同一性は保証できない。
